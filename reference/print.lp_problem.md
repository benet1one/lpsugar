# Print method for problems.

Print method for problems.

## Usage

``` r
# S3 method for class 'lp_problem'
print(x, full = FALSE, ...)
```

## Arguments

- x:

  An
  [`lp_problem()`](https://benet1one.github.io/lpsugar/reference/lp_problem.md).

- full:

  Boolean. If TRUE, linear constraints with less than 200 rows are
  printed fully. If FALSE, only prints a summary of each constraint.

- ...:

  Ignored.
