# Print method for aliases or transformed variables.

Print method for aliases or transformed variables.

## Usage

``` r
# S3 method for class 'transformed_lp_variable'
print(x, full = length(x$A) <= 20, ...)
```

## Arguments

- x:

  An alias or transformed variable.

- full:

  Boolean. If TRUE, prints the relevant fields. If FALSE, prints a
  compact summary.

- ...:

  Ignored.
